# Kanzo Harness 0.3.0-harness.6

This fork version adds agent feedback and reviewed learning to the native local
workspace, retaining upstream AGPL provenance and the `develop` integration line.

- Immutable, idempotent attributed reports in SQLite, with original project
  identity and observation/submission versions.
- Append-only revision-checked human reviews; only current-version verified
  lessons for the current project identity enter selected context.
- MCP `report_feedback`, `list_feedback`, `get_feedback`; no review/promote tool.
- Feedback list/report/review UI with pagination, draft-preserving conflict
  recovery, historical identity/version labels and bounded-page recovery.
- Portable `skills/kanzo-harness` workflow plus evidence/feedback/storage guides.

Schema8 adds feedback tables without changing shared task rows. Compatibility
and the existing writer marker remain7. Back up the complete private data and
executable before upgrade; reconnect MCP clients for new tool discovery. Current
JSON/Markdown exports are task-oriented; complete DB backups/sync carry feedback.

Source tags are immutable version references, not publication of a private board
or a claim of model training, multi-user authentication or causal improvement.
Feedback does not automatically mutate tasks, skills, memory or code. PostgreSQL
is a future Store/migration option; SQLite remains the implemented backend.

See [validation](../VALIDATION.md), [feedback](../FEEDBACK.md),
[storage](../STORAGE.md), and [the portable skill](../../skills/kanzo-harness/SKILL.md).
